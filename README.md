# AI Lab

A collection of AI, machine learning, reinforcement learning, simulation, and algorithm experiments.  
This repository contains projects built while exploring learning agents, optimization techniques, classic control environments, game-playing AI, and artificial life simulations.

Many of the reinforcement learning projects use environments from **Gymnasium/OpenAI Gym**, while others are standalone algorithmic or simulation-based experiments.

## Projects

| Project | Description |
|---|---|
| [`ant-colony-optimization`](./ant-colony-optimization) | Ant Colony Optimization experiments for pathfinding and combinatorial optimization problems. |
| [`bipedal-walker-v3`](./bipedal-walker-v3) | Reinforcement learning experiments with the Bipedal Walker environment. |
| [`boids-flocking`](./boids-flocking) | Boids-style flocking simulation based on simple local rules for collective behavior. |
| [`car-racing-v3`](./car-racing-v3) | Agent training experiments in the Car Racing environment. |
| [`cartpole-v1`](./cartpole-v1) | Classic CartPole reinforcement learning experiments. |
| [`flappy-bird-v0`](./flappy-bird-v0) | Game-playing agent experiments using a Flappy Bird-style environment. |
| [`gym-maze`](./gym-maze) | Maze environment experiments for reinforcement learning and pathfinding. |
| [`house-prices-prediction`](./house-prices-prediction) | Machine learning regression project for predicting house prices. |
| [`lunar-lander-v2`](./lunar-lander-v2) | Reinforcement learning experiments with the Lunar Lander environment. |
| [`maze-generator`](./maze-generator) | Maze generation algorithms and visualizations. |
| [`maze-v0`](./maze-v0) | Custom maze environment or maze-solving reinforcement learning experiments. |
| [`mountain-car-v0`](./mountain-car-v0) | Reinforcement learning experiments with the Mountain Car environment. |
| [`multi-armed-bandit`](./multi-armed-bandit) | Exploration vs. exploitation experiments using multi-armed bandit algorithms. |
| [`particle-life`](./particle-life) | Particle-based artificial life simulation using simple attraction and repulsion rules. |
| [`pendulum-v0`](./pendulum-v0) | Reinforcement learning experiments with the Pendulum control environment. |
| [`pong-no-frame-skip-v4`](./pong-no-frame-skip-v4) | Atari Pong reinforcement learning experiments. |
| [`super-mario-bros-v0`](./super-mario-bros-v0) | Reinforcement learning experiments with a Super Mario Bros environment. |
| [`taxi-v3`](./taxi-v3) | Tabular reinforcement learning experiments using the Taxi environment. |

## Topics Covered

This repository includes experiments related to:

- Policy learning
- Exploration vs. exploitation
- Game-playing agents
- Classic control problems

- Pathfinding
- Maze generation

- Machine learning regression
